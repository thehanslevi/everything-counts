# Check before you state

Notes, summaries and memory files from earlier sessions go stale. Before you tell the owner what is live, pending, deployed or still on a branch, check it against the real thing: the repo (`git log main`, `git merge-base --is-ancestor`, `git diff main...<branch>`), the live site, Vercel or Supabase. If you can't check something, say that it comes from notes and is unchecked. When something ships, update any note that still calls it pending.
